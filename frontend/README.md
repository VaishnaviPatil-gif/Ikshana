# AegisOcean - Frontend Client

High-performance maritime intelligence interface built with **React 19**, **Vite**, **Deck.gl**, **MapLibre GL**, and **Recharts**.

> For full project documentation, architecture diagrams, backend setup, and Docker deployment, please see the [Root README](../README.md).

## Quickstart

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build

# Code linting
npm run lint
```

## Role Dashboards

- **Public Safety Portal**: `/`
- **Coast Guard Tactical Center**: `/dashboard/coastguard`
- **Regional Operations Hub**: `/dashboard/regional`
- **Higher Maritime Authority**: `/dashboard/authority`
